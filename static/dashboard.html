Google Cloud BigQuery Schema & JSON Export

Export store design telemetry and demand transactions into Google Cloud BigQuery for enterprise AI forecasting.

Target BigQuery Schema (SQL DDL):
CREATE OR REPLACE TABLE `jewel_commerce.customer_requests` (
  request_id STRING NOT NULL,
  timestamp TIMESTAMP,
  category STRING,
  occasion STRING,
  style_motif STRING,
  metal_alloy STRING,
  stone_type STRING,
  carat_weight FLOAT64,
  budget_inr INT64,
  customer_name STRING,
  conversion_status STRING
)
PARTITION BY DATE(timestamp)
CLUSTER BY category, metal_alloy, occasion;
